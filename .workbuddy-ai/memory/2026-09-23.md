## Night Mode Visibility Fix (Request 3) — specific field readability (Social Media / Website Directory / GUI Management)
User reported (4 screenshots) that specific column values remained too bright/poorly contrasted in Night Mode:
1. **Social Media Accounts** — Department, Disposable, Recharge Date values
2. **Website Directory** — Origin, Automated values
3. **GUI Management** — Password, Role, Activity Log, AML Password values

### Root cause
Templates use **inline `style="background:#xxxxxx;color:#yyyyyy"`** on cell pills/badges (e.g. Department = `#e8f5e9`/`#1b5e20`, Origin = `#eaf4fd`/`#1a5276`, Disposable count badge = `#fff3e0`/`#e65100`, Automated No = `#fde8e8`/`#c0392b`, Recharge Date Expired = `#fff1f2`/`#be123c`). The previous visibility-fix pass added dark variants for `#e8f8f0`, `#eaf2ff`, `#fff5e6`, `#f0fff4` but missed the colors actually used by these specific cells. The GUI Management `.tag-*` classes also had no dark overrides — only the `.badge-*` family was recolored.

### Changes made (all in static/gui-base.css, new block lines 894-1014)
- **Social Media Department pill** `#e8f5e9` → green translucent + `#BBF7D0` text.
- **Number Type count badges**: Prepaid `#e8f5e9` (same selector), Postpaid `#e3f2fd` → blue translucent + `#BFDBFE`, Disposable `#fff3e0` → orange translucent + `#FCD9A6`.
- **Recharge Date pills**: Expired `#fff1f2` → red translucent + `#FCA5A5`, ≤3 days `#fff7ed` → orange translucent + `#FCD9A6`, healthy `#ecfdf5` → green translucent + `#BBF7D0`.
- **Website Directory Origin** `#eaf4fd` → blue translucent + `#BFDBFE` (existing rule only caught `#eaf2ff` — different color).
- **Website Directory Automated**: No `#fde8e8` → red translucent + `#FCA5A5`, other/N/A `#f5f5f5` → slate translucent + `#CBD5E1`. Yes `#e8f8f0` was already mapped.
- **GUI Management `.tag-*` classes** (used by Password / Role / Activity Log / AML Password / employee type): green, red, blue, gray, purple, orange all → matching translucent dark variants. Same palette as the existing `.badge-*` recolors so visual consistency is preserved.
- **GUI Management `.secret-value`** (masked `********` span inside Password and AML Password cells) → purple translucent + `#DDD6FE`, matching the original tag-purple intent.

### Cache-buster
- Bumped `?v=20260923-visibility2` → `?v=20260923-visibility3` across all 7 non-login templates.
